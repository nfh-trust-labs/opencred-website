Issue verifiable credentials from a desktop app or your own servers. Free, open source, and available today. Latest release v1.11.0.

macOS · Windows · Linux

Desktop App

A self-contained OpenCred client for individuals and small teams. Issue, manage, and export credentials directly from your laptop — no servers required. Signing keys never leave your machine.

macOS (Apple Silicon) .dmg macOS (Intel) .dmg Windows .exe Linux .AppImage Linux (Debian / Ubuntu) .deb

Verify downloads with the SHA256SUMS on the release page. macOS shows a one-time approval prompt on first launch; the installation guide has the steps.

Containerized · Production-ready

Docker Image

Deploy OpenCred on your own infrastructure. A headless HTTP API for organisations running credential issuance at scale, with full control over keys, storage, and deployment.

docker pull ghcr.io/nfh-trust-labs/opencred/opencred-server:latest

Pin a version tag in production. Configuration, reverse proxy, and HSM options are in the deployment guide.
